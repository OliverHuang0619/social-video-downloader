# 媒体库“等待分析”筛选设计

## 目标

在媒体库现有状态下拉框中增加“等待分析”选项，帮助用户快速找到尚未生成分析结果、卡片当前显示“等待分析”的视频。

## 行为

- “等待分析”定义为媒体条目的 `analysis` 字段为空。
- 选择“等待分析”后，仅显示没有分析结果的视频。
- 此筛选不受条目的 `processingState`（未处理或已处理）影响。
- 现有“未处理”“已处理”“全部状态”行为保持不变。
- 页面默认筛选仍为“未处理”。
- 搜索词和分类筛选继续与状态筛选组合生效。

## 实现边界

- 将媒体库过滤逻辑提取为可单元测试的共享函数。
- 扩展界面状态类型及状态下拉框，加入“等待分析”。
- 不修改数据库结构、服务端接口、卡片状态标签或分析任务流程。

## 测试

- 验证“等待分析”只返回 `analysis` 为空的媒体。
- 验证该筛选同时包含 `processingState` 为未处理和已处理的媒体。
- 验证现有处理状态筛选仍按原逻辑工作。
- 运行相关单元测试、类型检查和构建。
